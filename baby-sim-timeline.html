Baby Simulator Roadmap

From the current prototypes (web sim, Blender render, and the "study with me" video cut) to the final project package due December 4.

  1. Week 5 · class Wed Oct 7

    Settle design questions

    Questionnaire + research

    • Draft and send the parent questionnaire: scenarios where parents felt confused, and moments where they did a good job
    • Gather evidence: parenting styles, common parenting harms, long-term effects of each style
  3. Week 7 · class Wed Oct 21

    Midterm presentation Due

    • 3-minute talk: problem, concept, demo clip, early questionnaire findings, next steps
    • Complete the "continue, start, pause" midterm reflection
    • Rehearse twice against a timer
  4. Week 8 · class Wed Oct 28

    Build the scenario engine

    • Fold midterm feedback into the design
    • For every scenario, write 5 answer choices, one per parenting style
    • Map each choice to developmental factors that go up or down, differing by stage
    • Build the first of the 4 stage versions as a playable care loop
  5. Week 9 · class Wed Nov 4

    Test + memo draft 1 Due

    • Run 4–6 playtests with parents; record notes and short clips
    • First version of the 500-word project memo
  6. Nov 5–17 · no class Nov 11

    Expand to all 4 stages

    • Build the remaining stage versions with their own scenario prompts
    • Fix the top issues from testing
  7. Week 10 · class Wed Nov 18

    • Add family structures: single parent, two moms, two dads, and how co-parents discuss decisions
    • Second draft of the project memo
  8. Nov 19 – Dec 1

    Final polish

    • Final build and video export; organize project assets

  9. Week 11 · class Wed Dec 2
